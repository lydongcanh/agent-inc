# Privacy

Agent Inc watches tools that can see your code, your prompts and your terminal, so its privacy rules are strict and simple.

## The short version

- **Everything stays on your machine.** The game and the forwarder make no network requests: no telemetry, no analytics, no update checks.
- **Metadata only.** We record *that* your agent ran a tool. We never record *what* it ran or what came back.
- **You own the files.** Everything is stored in `~/.agent-inc/`. You can read it, and you can delete it at any time.

## What the agents send to the hook

Claude Code and Codex send each hook a JSON payload. Depending on the event, that payload can include your prompt text, tool inputs (shell commands, file contents being written), tool outputs, the agent's last message, your working directory and a path to the full session transcript.

## What Agent Inc keeps

The forwarder reads the payload in memory and writes only these fields (see the [event format](architecture.md#event-format-v1)):

| Kept | Example |
| --- | --- |
| Event type and original hook name | `tool.start`, `PreToolUse` |
| Agent name | `claude-code` |
| Session ID and subagent ID | Random IDs generated by the agent |
| Tool name and category | `Bash`, `run` |
| Project folder name (the last part of the path only) | `my-app` |
| Timestamp | `2026-11-03T15:04:05.123Z` |

## What Agent Inc never keeps

- Prompts, or messages from the agent
- Tool inputs: commands, file contents, diffs, search queries, URLs
- Tool outputs and error messages
- Full file paths, including your working directory and home directory
- The session transcript. The game never opens `transcript_path`.
- Credentials of any kind. Agent Inc never reads agent config or auth files, other than writing hook entries to the config files when you click **Connect agents**.

## Retention

The game deletes session files older than 7 days by default. You can change this in settings, or delete `~/.agent-inc/sessions/` yourself at any time.

## Future features

Some planned features, such as showing which file is being edited or chatting with agents, would need more data. Each one will be **opt-in**, off by default, and documented here before it ships.

## Reporting a privacy problem

If you find that Agent Inc stores or sends more than this page says, please open an issue. Describe the problem without pasting real payloads or session files.
